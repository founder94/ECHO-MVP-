## 4. 남은 문제 · 확인 불가 · 승인 대기

- **목표 미달**: 실제 AI 첫 질문이 방금 답(「천천히 대화하면서 스며드는 친구」)과 이어지지 않음 1건(「처음 만날 때 밥부터 먹는 게 좋아요?」). 확률적 품질 — 재현 빈도 측정 후 서버 질문 검사 보강 여부 결정.

- **확인 불가**: 아이폰 사파리 실기기(주소창·키보드·터치) · 컨테이너 브라우저의 QA 앱 화면 그리기(프록시) · 실제 Google 로그인 왕복.
