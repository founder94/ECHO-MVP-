- 근거: 대표 실기기 사용 설명(2026-09-26 「REAL DEVICE P0 UX FIX」 지시문), 운영 DB 읽기 전용 조회(쓰기 0), 코드 읽기.
- 캡처 이미지 6장은 이 작업 대화에 파일로 오지 않았다. 캡처 내용은 지시문의 설명으로만 확인했다.

## 실기기에서 아직 확인하지 않은 것 (확인 불가)

- 아이폰 사파리
  - 마이크 권한 창이 뜨는지.
  - `webkitSpeechRecognition` 이 실제로 한국어 글자를 돌려주는지.
  - 음량 0 소리 열기 뒤 서버 대답이 소리로 나오는지.
- 홈 화면 앱(standalone)으로 열었을 때 음성 인식이 되는지. 애플 정책상 막힐 수 있다. 막히면 「마이크를 쓸 수 없어요」 안내가 뜬다.
- 갤럭시 크롬
  - 같은 흐름이 되는지.
  - 설치 창이 뜨는지.
  - 설치 뒤 Metal E 아이콘이 보이는지.
- 외부 음원 2곡이 실제로 재생되는지, 시간이 제대로 표시되는지.
