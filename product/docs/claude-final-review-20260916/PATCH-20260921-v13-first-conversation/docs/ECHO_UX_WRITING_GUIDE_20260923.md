# ECHO / DO IT UX 라이팅 원칙 (2026-09-23)

> 대표 지시: "폰트가 너무 AI가 만들어준 느낌, 사람 냄새 나게. 글의 품질도 개선. 너는 지금부터 UX 라이팅 전문가."
> 이 문서는 앱 화면 문구를 새로 쓰거나 고칠 때의 기준이다. 홈 히어로·랜딩 문구는 이 문서로 바꾸지 않는다(대표 승인 구역).

## 1. 한 줄 원칙
**옆 사람에게 말하듯 쓴다.** 시스템이 사용자에게 보고하는 말투가 아니라, 사람이 사람에게 건네는 말.

## 2. 쓰는 법 7가지
1. **주어는 나/내가.** "당신의 이해" 대신 "내가 맞다고 한 말".
2. **한 문장에 한 생각.** 쉼표로 두 생각을 잇지 않는다.
3. **기계 말을 빼고 사람 말로.** 「AI의 이해」→「AI가 이렇게 들었어요」, 「회차」→「이번에 / 지난번」, 「자격이 갖춰져요」→「연결을 받을 수 있어요」.
4. **「~하고 있어요」를 줄줄이 쓰지 않는다.** 기다림 문구는 무엇을 하는지 구체적으로: 「이야기를 정리하고 있어요」→「방금 한 말을 읽고 있어요」.
5. **없는 기능을 약속하지 않는다.** 연결(추천)은 아직 열리지 않았다. 「AI가 사람을 찾기 시작해요」 금지 →「연결은 아직 열리지 않았고, 열리면 가장 먼저 알려 드릴게요」.
6. **버튼은 할 일로 끝낸다.** 「준비하기」보다 「사진과 소개 채우기」, 「이 설명으로 저장하기」보다 「이렇게 저장할게요」.
7. **꾸밈을 빼고 담백하게.** 줄표(—), 화살표 남발, 광고 문구, 과장된 공감 금지. 쉼표 대신 마침표.

## 3. 절대 바꾸지 않는 것 (대표 결정)
- 첫 질문 「어떤 만남을 원하세요?」 + 목적 고르기 + 「한 줄 더 적기」
- 「당신이 잠든 사이」 문구와 그 아래 문구
- 네 버튼: 맞아요 / 조금 달라요 / 그게 아니에요 / 직접 설명할게요
- 화면에 쓰지 않는 단어: 데이팅·소개팅·궁합·점술·심리치료·성격검사

## 4. 자주 쓰는 말 바꾸기
| 쓰지 않는 말 | 쓰는 말 |
|---|---|
| 내가 확인한 이해 | 내가 맞다고 한 말 |
| 아직 확인하지 않은 AI의 이해 | AI가 이렇게 들었어요 |
| 이 설명이 내 생각과 맞나요? | 내 생각과 같나요? |
| 연결 자격이 갖춰져요 | 연결을 받을 수 있어요 |
| 사진·소개 준비하기 | 사진과 소개 채우기 |
| 대화 이어가기 | 이어서 답하기 |
| 연결 준비 상태 보기 | 연결까지 남은 것 보기 |
| 이번 대화 n개 / 이전 회차 | 이번에 한 답 n개 / 지난번 이야기 |
| 기록을 불러오지 못했어요 | 잠깐 연결이 끊겼어요 (+ 적어 둔 건 지워지지 않았다는 말) |
| 조금 오래 걸리고 있어요. 인터넷 연결을 확인하고 다시 시도해 주세요. | 생각보다 오래 걸려요. 인터넷이 잘 되는지 확인하고 다시 눌러 주세요. |

## 5. 바꾼 주요 문장 (전 → 후)
| 화면 | 전 | 후 |
|---|---|---|
| 앱 홈(시작 전) | 이 다섯 가지 답이, 당신에게 누구를 소개할지 정하는 재료예요. | 여기에 답한 말로 어떤 사람을 소개할지 정해요. |
| 대화 시작 안내 | 짧게 한 줄이면 충분해요. 다 적으면 AI가 조건이 맞는 사람을 찾기 시작해요. 다섯 개를 넘겨서 묻지 않아요. | 한 줄이면 충분해요. 딱 다섯 개만 묻고 끝낼게요. |
| 대화 끝 | 다섯 가지, 다 들었어요. 이제 상대를 찾을 차례예요. | 다섯 가지, 다 들었어요. 이제 나를 보여 줄 차례예요. |
| 대화 끝 설명 | 이제 같은 만남을 원하는 사람 중에서, 답이 겹치는 사람을 찾기 시작해요. | 다음은 나를 보여 줄 차례예요. 연결은 아직 열리지 않았고, 열리면 가장 먼저 알려 드릴게요. |
| 시작 흐름 선택 | 이어서 할지, 내가 고를 수 있어요. | 오늘은 무엇부터 할까요? |
| 입력창 아래 | 대화는 내 계정에 저장돼요. 프로필에 자동 공개하지 않아요. | 적은 말은 나만 봐요. 프로필에 저절로 올라가지 않아요. |
| 고치기 창 | 어떤 부분을 고치면 더 맞을까요? | 어디가 다른지 알려 주세요. |
| AI 문장 카드 | 아직 확인하지 않은 AI의 이해 / 이 설명이 내 생각과 맞나요? | AI가 이렇게 들었어요 / 내 생각과 같나요? |
| 기다림(대화 준비) | 대화를 준비하고 있어요. | 첫 질문을 꺼내고 있어요. |
| 기다림(화면 이동) | 화면을 준비하고 있어요. | 다음 화면을 여는 중이에요. |

## 6. 글꼴
- 제목·질문·내가 쓴 말·AI가 들은 문장: **고운바탕** (붓의 결이 남은 한글 바탕체)
- 안내 문장: **고운돋움** (같은 집안의 돋움체) — 굵은 글자가 없으므로 강조는 고운바탕 굵게
- 버튼·탭·작은 글씨: 그대로(읽기 쉬운 것이 먼저)
- 한글 머리말에 넓은 자간(.15em 이상)을 주지 않는다. 틀에 찍은 느낌이 난다.
- 규칙 파일: `src/doit/components/feature/doit-type.css` (앱 화면 범위 안에서만)
- 글꼴은 `index.html` 에서 화면을 멈추지 않게 뒤에서 받는다. 화면 조각 스타일 안에서 `@import` 하지 않는다(구글 폰트가 막히면 화면 전체가 멈췄던 원인).
