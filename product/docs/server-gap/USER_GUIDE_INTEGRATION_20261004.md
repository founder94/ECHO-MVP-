## 2. 구현

- 내용 한 벌: `src/lib/guide/content.ts`. 홈페이지·앱 창·설정 #guide 가 모두 이 파일을 쓴다(따로 복사 0).
- 안내 창: `src/components/guide/GuideHost.tsx` + `guide.css`
  - 넓은 화면(900px 이상)에서는 오른쪽 패널, 휴대폰에서는 아래에서 올라오는 창이다.
  - 화면을 옮기지 않는다(포털). 그래서 적던 글·스크롤·고른 것이 그대로 남는다.
  - 폰 「뒤로」·닫기·Esc 모두 창만 닫는다.
  - 열려 있는 동안 키보드 초점은 창 안에 머물고, 닫으면 원래 자리로 돌아간다.
  - 읽는 동안 뒤 화면의 움직임을 멈춘다. 움직임 줄이기면 애니메이션 0.
- 열기: `src/lib/guide/bus.ts` 의 `openGuide(항목)`.
- 기능 옆 짧은 도움말: `src/components/guide/GuideHint.tsx`
  - 처음 한 번만 한 줄 + 「자세히 보기」·「닫기」를 보여 준다. 그 뒤에는 「이 기능이 궁금해요」 링크만 남는다.
  - 닫은 기록은 이 기기 브라우저(localStorage)에만 남는다. 새 DB 0이고, 다른 기기에서는 다시 보일 수 있다.
  - 동의 값은 바꾸지 않는다.
- 진입점
  - 홈페이지: 메뉴 「이용 안내」 · 바닥글 「이용 안내」 · 「앱 설치 안내」(설치 항목이 펼쳐진 채 열림).
  - 앱: 오른쪽 위 메뉴 「이용 안내」(옛 「ECHO 사용법」) · 첫 질문·확인 단계·후보 목록·찌릿 화면 옆.
  - 새 탭·주소로는 설정 #guide 가 같은 내용을 보여 준다.
- 대화 화면의 「뒤로 = 직전 답 고치기」는 안내 창을 닫는 뒤로에는 반응하지 않게 했다. 브라우저 검사 70에서 실제로 글이 바뀌는 것을 발견해 고쳤다.
