# doit-agent v2.3 제안: 받아주기 평가 말 금지 · 질문 더 가볍게 (2026-09-26)

**상태: 제안만 했다. 운영 서버에는 v2.2가 그대로 있다.**

- 이 브랜치의 `agent.ts`는 v2.2 그대로다.
- 바꿀 내용은 `doit-agent-v2.3-human-tone.patch`에만 있다(`git apply --check` 통과).

## 왜 필요한가

1. **받아주기가 평가하는 말로 나온다.**
   - 운영 기록(2026-09-26, v2.2)에 「부담스럽지 않게 대화 나누는 건 좋은 방법이죠.」가 있다.
   - 대표 기준은 칭찬·판정 없이 들은 뜻만 짚는 것이다.
2. **질문이 무겁다.**
   - 질문 문장은 AI가 만든다.
   - 그래서 앱 화면만 고쳐서는 바뀌지 않는다. 서버 프롬프트를 바꿔야 한다.

## 바꾸는 것

| 위치 | 지금 (v2.2) | 제안 (v2.3) |
|---|---|---|
| 첫 질문(서버 고정 문장 1개) | 어떤 만남을 원하세요? | 요즘은 어떤 만남이면 좋겠다 싶어요? |
| 받아주기 규칙 | 해석·평가 0 | 칭찬·판정 말 0, 상담사 말 0, 들은 뜻만 1~2문장. 예시는 결만 보여 주고 그대로 쓰지 않는다. |
| 질문 규칙 | 밝고 가볍게 | 금지어(당신은·귀하는·관계에서·가치관·성향·선호·이상형·조건·분석·진단). 「~하는 편인가요」 반복 금지. 추상어는 하나까지, 두 줄 안쪽. |

- 목적 5개, 최대 5개, 서버 가드, 정정·거절 규칙은 바꾸지 않는다.

## 적용 순서 (대표 승인 필요)

1. 이 패치를 적용하고, 버전 검사 2개를 v2.3 값으로 바꾼다. 패치를 잠깐 적용해 검사한 결과, 버전 문자열 검사와 첫 질문 문장 검사 2개만 달라졌다(598 통과 / 2 실패).
2. 실제 AI 검사를 한다(gpt-4o-mini, `run-request.json`). 비용이 드는 검사라 **대표 승인 전에는 하지 않았다.**
3. 검사를 통과하면 doit-agent만 운영에 반영한다. **운영 서버 배포는 STOP(대표 승인 필요).**
