| 3 | **공통 색 토큰이 '짙은 청록 판'** | `echo-ui.css` 의 `--echo-glass: rgb(30 42 48 / .50)` 를 `bg-background-*`·`bg-black` 가 들어간 모든 판이 쓴다. 그래서 시안의 '밝은 유리'가 아닌 어두운 판이 많아졌다. 윗줄 `.doit-product-topbar` 도 `rgb(30 42 48 / .62)` 라서, 홈·프로필 위에 짙은 띠가 생긴다. |
| 4 | **햄버거가 화면 위에 따로 떠 있음** | `app-corner-menu.css` `.echo-corner-button { position: fixed; top: …; right: 12px }` 이다. 화면 머리줄과 따로 떠서 글·말풍선·「뒤로」 알약과 겹친다(대표 캡처: 타로 제목, 대화 말풍선). 시안은 머리줄 안 오른쪽(`ECHO … ≡`)이다. |
| 5 | **화면 하나에 설명·버튼이 많음(옛 안전 문구 누적)** | 대화 화면에 질문 외 문구 7줄이 있다(「이번에 한 말 N개」 펼치기, 「이어서 적기」, 「적은 말은 나만 봐요…」, 「잘 모르겠어요 / 이 질문 넘어가기」 큰 버튼 2개, 「오늘은 여기까지」, 아래 「사진과 소개 채우기」). 시안은 질문 + 입력칸 하나다. |
| 6 | **검사가 '글자·구조'만 봄** | 지금까지의 검사는 문구·클래스(정규식)와 넘침만 확인했다. 승인 시안 그림과 나란히 보는 검사가 없어서, 달라져도 PASS 였다. |
| 7 | (기능 · 이번 범위 밖) **타로 해석이 QA에서 항상 실패** | QA 에는 `openai-chat` 함수가 없다(읽기 전용 함수 목록으로 확인). 그래서 「잠시 후 다시 시도해 주세요」가 뜬다. 디자인이 아니라 서버 배치 문제라서 대표 결정이 필요하다. |
| 8 | (질문 품질 · 이번 범위 밖) 「원해요로 시작해 첫 만남에 바로 카페로…」 | AI 질문 문장이 어색하다. 질문 로직은 이번 금지 범위라서 서버 담당에게 따로 넘긴다. 단, 화면 제목이 「연애로 이어질 만남을 원해요 편하게 몇 가지만 물어볼게요.」처럼 목적과 제목이 한 줄로 붙는 것은 **화면 문제라 이번에 고친다**. |

## 4. 고칠 순서(이번 범위 = 화면·문구만)

   - 햄버거를 머리줄 안 자리에 넣는다(겹침 0).
2. 홈·「오늘은 무엇부터」·프로필

   - 1화면 안에 들어가게 한다(프로필 상세는 접기).
3. 대화
   - PR131 대화 화면을 기반으로 사용자 아바타와 입력 중 점을 넣는다.
   - 「이어서 적기」 등 보조 문구를 줄인다.
   - 목적·제목이 붙어 나오는 줄을 분리한다.
4. 타로 결과: 「뒤로」 알약과 제목이 겹치지 않게 한다.
5. 검사

   - 짙은 판 개수, 스크롤 1화면, 겹침 0 을 숫자 검사로 둔다.
6. 합치기·게시 순서(2026-10-05 정정 · Codex echo-review 5993217604 ④):
