## 흡수 항목 정리 (실행은 승인 후)
1. **홈 BGM YouTube 숨김 재생 = 약관 리스크.** 선택지: (a) 플레이어를 보이게(최소 200×200) 두거나, (b) 대표 원음(A 카드와 같은 자체 mp3)으로 홈 BGM 교체, (c) 홈 BGM 제거. 권장 **(b)**: 라이선스 0, 광고 0, 디자인 변화 최소. 히어로·랜딩 수정은 STOP 게이트 → 대표 승인 후 래디 작업.
2. 정책 원칙 기록: 광고·음악 유료화·데이터 판매 금지, Spotify/MusicKit/Deezer/자체 호스팅/유튜브 오디오 전용 도입 금지.
3. 가격 근거: 4,900원 실수령 = PG 수수료 차감 후. 결제 개통 시 정산 표에 반영.
4. 백로그(하드닝 종료 후): 기간 회고 리포트 → 선물하기 → 구독(승인 필요).
