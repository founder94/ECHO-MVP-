## 1. 남은 P0-08 경로 확정 (추측 아님)

문제의 1턴:

> 사용자: "내가 언제 그렇게 말했어?"
> 서버: "어떤 생각에 대해 궁금하신 건가요?"

**확정 경로:** 운영 로그 `asked_reply_failed` **1건**.
모델이 답(reply) 후보를 3번 다 못 만들면 `replyOnly` 구제가 `reply: ""` 를 돌려주고,
렌더는 답이 비면 **질문만** 낸다. 대화는 이어지지만 사용자의 직접 질문이 무시된다.

**내 직전 보고 정정:** "asked_reply_failed 0건"이라고 했는데 틀렸다. 로그 조회가 `limit 20` 에 잘렸다.

**최소 수정 (공통 Core):** `groundedBasisReply(ctx)` — 없는 사실을 만들지 않고,
사용자가 실제로 한 말을 그대로 인용해 '무엇을 근거로 삼았는지'만 밝힌 뒤 대화를 잇는다.
인용할 말이 없으면 만들지 않는다. 금지어가 든 문장은 인용하지 않는다.

**실패검사:** 문장 하나를 통과시키지 않는다. 같은 의미군 4문장
("내가 언제 그렇게 말했어?" / "왜 그렇게 생각했어?" / "그 판단은 어디서 나온 거야?" / "난 그런 말 한 적 없는데 왜 그래?")
전부에 대해 ① 질문으로 되받지 않을 것 ② 답이 사용자 원문에 근거할 것을 본다.
수정 제거 → FAIL, 복원 → PASS (역검증 완료).

**운영 확인:** 배포 후 캐너리에서 `asked_reply_failed 1건 · basis=1` → **사용자질문무시 0건.**
