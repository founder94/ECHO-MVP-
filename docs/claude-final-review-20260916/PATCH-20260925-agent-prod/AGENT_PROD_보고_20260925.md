## 기능
- **에이전트**
  - 목적 5개(원하는 만남 · 편하거나 끌리는 사람 · 사람을 볼 때 중요한 것 · 알아가는 방식과 속도 · 꼭 있었으면/피하고 싶은 것)
  - 핵심 질문은 최대 5개. 6번째 질문은 서버가 막는다.
  - 첫 질문은 기존 목적 타일 화면이다. 타일과 한 줄이 곧 첫 답이다.
- **먼저 답하기**: 사용자가 질문하면 먼저 답하고, 답을 못 받은 지금 질문을 그대로 둔다(질문 수는 늘지 않는다).
- **정정·항의**: 저장하지 않는다. 틀린 기억은 거두고, 문제 삼은 질문으로 다시 가지 않는다.
- **넘기기 → 다음 목적**
  - 「이 질문 넘어가기」 버튼이 있다.
- **지침·그만**: 들은 만큼 정리하고 마친다.
  - 「여기까지 할게요」 버튼이 있다.
  - 대화는 최대 20턴이다. 끝난 뒤 고치기는 5번까지 받는다.
- **말투**: 3종(정중한 존댓말 · 편한 존댓말(기본) · 편한 반말)
  - 매 턴 AI 에 전달한다.
  - 예시 문장은 삭제했다(AI 가 그대로 베꼈기 때문).
- **글/말**
  - 말로: 휴대폰 키보드 마이크로 받아쓰기 → 글자로 전송 → ECHO 대답을 기기 음성으로 읽음
  - 화면 상태 표시: 「생각하는 중이에요」 · 「ECHO 가 말하는 중이에요 / 소리 멈추기」 · 「다시 듣기」
  - 목소리 원본 저장 0, 새 키 0
  - 실시간 음성은 STOP이다. 서버 함수와 키 사용 승인이 필요하다(`docs/failure-intelligence/VOICE_RESEARCH_20260925.md`).
- **매칭 프로필**
  - 목적별 CONFIRMED(원문 인용이 확인된 것만) / SKIPPED / UNKNOWN
  - 추측은 INFERRED 로 따로 두고 매칭에 쓰지 않는다.
  - MBTI·혈액형은 사용자가 직접 말했을 때만 넣는다.
- **매칭 넘기기**: 상태는 `NOT_CONNECTED`, 후보는 [].
  - 연결 서버(doit-connect)는 아직 이 프로필을 읽지 않는다. 그대로 적는다.
- **관리자**: `/doit/admin/mobile` → 「대화 에이전트」
  - 서버가 관리자 역할을 다시 확인한다.
  - 실제로 저장된 세션·턴만 보여 준다. 원문은 기본으로 가린다.
  - 보여 주는 것:
    - 대시보드
    - 대화 보기
    - 매칭 프로필
    - 실패·성공 후보(자동 · CANDIDATE)
    - AI 관측(모델·토큰(usage)·지연·다시 청함·오류)
  - 비용은 「확인 불가」로 표시한다(공식 단가를 확인하지 못했다).
- **「시작하기」 선택창**
  - 앱 히어로의 「ECHO 시작하기」를 누르면 히어로 위에 무채색 창 하나만 뜬다.
    - 덮개 0 · 흐림 0 · 스크롤 잠금 0
  - 고르면 원래 가던 길(`/doit/start-journey`)로 간다. 대화 화면에서 다시 묻지 않는다.
  - 다른 길(앱 홈 「시작하기」, 처음부터)로 들어오면 대화 화면 위에서 같은 창이 뜬다.
- **대화 화면**: 기존 대화 화면(CoreConversation)의 배치·클래스를 그대로 쓴다. 새 CSS 는 선택창 파일 하나(`agent-choice.css`, `.echo-choice-layer` 아래로만)다.

## 남은 문제 (FAIL · 목표 미달 · 확인 불가)
- **목표 미달**: gpt-4o-mini 가 뜻을 뽑아 저장하는 양이 적다(10개 대화에 확인된 정보 10개).
  - 원인: 오타가 있는 답에서 인용을 고쳐 써서 서버의 원문 대조에 걸린다.
  - 그만큼 매칭 프로필이 비고, 목적 하나를 두 번 묻는 경우가 있다(첫 답이 저장되지 않으면 「어떤 만남」을 다시 물음 — gpt-4.1 재생에서 관측).
- **목표 미달**: 설문처럼 들리는 질문이 아직 남아 있다(37개 중 7개, 추정 지표).
  - 이어짐·자연스러움은 기계로 판정하지 않았다.
- **FAIL(관측)**: 「활동?갑자기?」처럼 되묻는 말을 답으로 읽고, 같은 질문을 다시 보인 경우가 있다(gpt-4o-mini FLOW2).
- **연결 자격과 다름**: 연결 자격(doit-connect)은 여전히 「다섯 답」을 센다. 에이전트는 넘기기·한 답에 여러 목적 때문에 기록이 5개보다 적을 수 있다.
  - 지금은 전화 인증 0명이라 영향 0이다. 대표 결정이 필요하다.
- **확인 불가**

  - 운영 관리자 화면(관리자 로그인이 필요)
  - iPhone Safari/Chrome · Galaxy Chrome · 삼성 인터넷 실기기
  - 아이폰에서 소리가 실제로 나는지
  - 비용(공식 단가 미확인)
