## 5. 파스텔 위 흰 글자 — 숫자 그대로

- 이 파스텔은 밝다. 노랑 구간의 휘도가 약 .8 이다. 그래서 흰 글자는 그림자 없이 **최대 약 2:1** 이다.
- 대표 지시대로 글자 뒤에 판이나 덮개는 깔지 않았고, 그림자만 썼다. 그림자 5단계를 쟀다.
  - 절제된 2겹 → 부드러운 3겹 → 검은 1px 윤곽 2겹 → 더 진한 윤곽
  - 글자 바로 옆 1~2px 대비(중앙값)는 윤곽까지 올려도 부드러운 3겹과 같았다.
  - 그래서 가장 절제된 쪽인 부드러운 3겹을 골랐다.

| 글자 (360·390·430·1440 × 4상태) | 표준 계산(그림자 제외) 최저 / 중앙 / 최고 | 글자 바로 옆 1~2px(그림자 포함) 최저 / 중앙 / 최고 |
|---|---|---|
| 질문·제목 23개 | 1.29 / 1.47 / 1.69 | 1.96 / 2.11 / 2.69 |
| 그 밖 127개(2순위 등) | 1.09 / 1.33 / 1.88 | 1.47 / 1.75 / 2.50 |

- 표준 기준은 작은 글씨 4.5:1, 큰 글씨 3:1 이다. 어두운 판이나 덮개 없이 흰 글자로는 **닿지 않는다.**
- 캡처로 보면 큰 질문은 읽힌다. 작은 안내 글씨(머리말·안내 문장)는 민트·노랑 구간에서 약하다.
- 이 캡처는 기기 배율 1배로 찍었다. 실제 휴대폰은 3배 배율이라 가장자리가 더 또렷할 수 있다. 실기기 확인이 필요하다.
- 대표가 고를 수 있는 길(이번에 하지 않음):
  - ① 지금대로 둔다.
  - ② 질문 블록 뒤에도 같은 유리를 깐다. 판을 새로 까는 것이라 대표 승인이 필요하다.
  - ③ 파스텔 전체에 옅은 덮개를 깐다. 배경 변경이라 대표 승인이 필요하다.
