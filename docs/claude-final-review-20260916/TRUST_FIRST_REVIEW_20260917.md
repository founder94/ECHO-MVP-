## 질문 응답 / 정정·거절 / 기억 / 재접속 / 지속 대화
- **질문 응답**: STEP 1·2·이해 후속·STEP 3~7·리포트 이후 모두 되물음을 '답할 말'로 처리한다. 단계는 진행되지 않는다. 지시서의 네 문장(오타·대처·답 안 함·정정+질문)을 검사로 고정했다. 답변 품질(관련성·완결성·회피 금지)을 서버가 판정하며, 통과하지 못하면 화면에 내보내지 않고 재시도한다.
- **정정·거절**: 거절한 해석은 질문·의미·답변·이해 요약에서 모두 차단. 리포트 '확정'은 사용자가 스스로 밝힌 말만 근거로 인정하고, 사용자의 질문·전언은 확정 근거에서 뺀다.
- **기억(실측)**: `doit_insights`(사용자·카테고리·본문·AI본문·상태 confirmed/corrected/rejected·출처 ai/self·개정번호) 와 `doit_records`(원문·정정본·상태)가 이미 존재하고, `service_role` 만 쓰기·사용자는 본인 행만 읽기(RLS)로 잠겨 있다. **새 테이블 없이 재사용 가능**하다. 이해 확인 4버튼 결과를 기억으로 저장하고, 다음 대화에서 '확인한 기억'으로만 불러온다(거절본 제외, 오래된 기록은 '확인 필요' 표시).
  - 현재 데이터: doit_records 0행, doit_insights 0행, reports 0행, 결제 0건, 대화 12건(2명). 즉 **지금까지 기억으로 쓸 데이터가 하나도 없었다**. 3차에서 넣은 '지난 리포트 요약'도 리포트가 0건이라 실제로 작동한 적이 없다.
- **재접속**: 같은 토큰 재전송은 저장을 중복하지 않고 저장된 상태를 돌려준다. 다른 계정은 403. 90초 지난 죽은 요청은 새 요청이 인계한다. 실기기·다른 기기 재접속은 미실행.
- **지속 대화**: 리포트 이후에도 완료 상태를 되돌리지 않고 대화를 잇는 서버 경로를 만들었다(결제 권한 필요). **화면이 없어 실사용은 아직 불가**.

## 미구현·미검증·남은 결함
1. **화면 없음**: 리포트 이후 지속 대화는 서버만 있다. 화면은 래디/Codex 작업이 필요하다.
2. **답변의 '정확성'은 자동 검사 불가**: 관련성·완결성·회피·금지어·거절 재등장까지만 기계가 판정한다. 사실 정확성은 사람이 봐야 한다.
3. **실제 AI 미호출**: 모든 검사는 가짜 응답 기준이다. 실제 모델이 이 규칙을 얼마나 자주 통과하는지는 배포 후 `candidates_blocked reasons=` 로그로만 알 수 있다.
4. **실기기 미확인**: 갤럭시 Chrome·아이폰 Safari 실기기 확인 없음(에뮬레이션만). WebKit 엔진 자체가 이 환경에 없다.
5. **Codex 수리본 대조 불가**: 파일 미보유.
6. **기억은 지금부터 쌓인다**: 과거 대화는 기억으로 소급 저장되지 않는다.
7. **무료 대화의 장기 기억**: 이해 확인 버튼을 누른 내용만 기억이 된다. 그 밖의 자유 답변을 장기 기억으로 남기려면 별도 설계·승인이 필요하다.
8. 답변만 하고 질문을 붙이지 않는 턴에서 사용자가 아무 말도 하지 않으면 대화가 멈춘다(사용자 입력 대기 상태). 재촉 문구는 넣지 않았다.
