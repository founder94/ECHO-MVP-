## 0. 내 실수 먼저

1. **GF-95 — 개인정보 처리방침 초안이 사실과 달랐다.** 9/22 에 사진 AI 확인(`doit-photo-check`)을 운영에 올렸는데, 이 기능은 사진을 OpenAI 로 보낸다. 그런데 초안에는 "사진은 보내지 않는다"는 문장이 남아 있었다. 사진 기능을 올릴 때 약관 초안을 같이 고치지 않았다. → 초안 문장을 사실대로 고쳤고 `[대표·법무 확인 필요]` 표시를 달았다. 이미 동의한 회원을 어떻게 할지는 대표 결정이다(아래 5절 ②).
2. **투명도 계산 오류.** 앱 화면 판(카드) 투명도를 처음에 .78 이면 글자 대비 4.5:1 을 넘는다고 적었다. 노란 파스텔 위에서는 넘지 못했다. 다시 재어 .81 이 최소값이다. 코드 주석도 고쳤다.
3. **자동 판정이 뜻 왜곡을 다 잡지 못한다.** run 15 에서 운영 모델(gpt-4o-mini)은 뜻 왜곡이 0건이었다. 그런데 비교용 gpt-4.1-mini 초안 1개가 상대에게 바라는 말 「행동으로 보여줄때」를 「(저는) 행동으로 진심을 보여줍니다」로 바꿨고, 내가 만든 자동 판정(`intro_self_claim`)은 이것을 세지 못했다. 그래서 화면은 언제나 「AI가 대화에서 정리 · 확인 필요」로 보이고, 사용자가 직접 누를 때만 저장된다.
