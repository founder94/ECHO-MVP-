■ 6. 얼굴·사진 인증의 실제 설계 [코드·운영] — SMS 와 별개, 삭제하지 않음
- "얼굴 로그인" = 패스키. 휴대폰의 Face ID·지문으로 로그인만 한다. 얼굴 정보는 휴대폰 밖으로 나가지 않는다. 본인 인증·실명 확인이 아니다. 운영 Passkeys 켜짐 여부는 [확인 불가]이고, 등록은 0개다.
- 사진 = 필수 3칸(전신·패션·취미) + 자유 3칸.
  - 최근 2개월 여부: 사진 파일 정보(EXIF)로 보고, 없으면 사용자 본인 체크를 받는다.
  - AI 판별(doit-photo-check 버전 1): 사람 있음·한 명·종류·화면 재촬영·안전·화질.
  - AI 판별 결과는 화면 배지로만 보인다. DB 에 저장되지 않는다(check_* 칸 없음[운영]). 연결 자격에도 쓰이지 않는다.
  - 본인 여부·실제 촬영일은 확인하지 못한다고 화면에 명시돼 있다.
- 연결 자격 = 전화 인증 + 다섯 가지 답 + 필수 사진 3장 + 대표 사진 + 소개. 사진은 "몇 장 있나"만 보고, AI 판별 결과는 보지 않는다.
