## 6. ZIP
40차 = 앱 + 홈페이지 2개(38·39차 내용 포함). 해시는 `ZIP40_SHA256.txt`.
운영 홈페이지는 36차(index.html 글자 단위 대조로 확인), 앱은 37차로 추정(Netlify 업로드 시각 21:27Z 가 37차 ZIP 21:24Z 뒤·38차 21:41Z 앞 — 앱 주소는 이 환경에서 접속 불가라 내용 대조 못 함).
