## 7. openai-chat
- 운영 버전 2, verify_jwt=false[운영]. 함수 안 로그인 확인(getUser) **없음**[운영 코드·로컬 코드]. 두 가지는 별개이며 둘 다 없음.
- 필요한 것: `x-anon-session`(아무 UUID) + Origin 허용 또는 **Origin 없음(브라우저 밖 요청)은 통과**[코드 `if (!origin) return true`].
- 호출 제한: 하루 15회·3초 간격이지만 **세션 번호 기준만**(IP 는 기록만)[운영 DB 함수]. 세션 번호는 호출자가 마음대로 만든다 → 로그인 없이 OpenAI 비용을 쓰게 할 수 있음[코드로 확인, 실제 공격은 안 함].
- 서비스 역할 키: 함수 안에서만, 응답·로그로 나가지 않음[코드].
- 운영 위험: 비용 남용(중). 고치려면 운영 배포 = STOP.
