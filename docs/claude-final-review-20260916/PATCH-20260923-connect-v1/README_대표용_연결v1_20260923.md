# 연결 v1 — 전화 인증부터 사람끼리 이어지기까지 (2026-09-23)

근거: 대표 2026-09-23 "지금 어디까지 구현을 해야 되는 단계까지는 승인하니까 허용하고 끝까지 진행시켜" + 연결 원칙(대표 확정 2026-09-21).

**아직 아무도 실제로 써 보지 않았습니다.** 아래 검사는 모두 가짜 서버·가짜 AI 기준이고, 운영에서 진짜 두 사람이 이어진 적은 없습니다.

## 1. 이번에 생긴 흐름

1. **전화 인증** (`/doit/verify`) — 휴대폰 번호 → 문자 6자리 → 확인. 예전 "데모 본인인증"(1.5초 뒤 저절로 완료) 화면은 없앴습니다.
   - 인증됐는지는 화면이 정하지 않습니다. Supabase 로그인 서버가 확인한 기록을 연결 서버가 다시 보고 프로필에 "인증함"을 적습니다.
   - 언제든 「나중에 할게요」로 나갈 수 있습니다. 문자 서비스가 아직 안 켜져 있으면 "지금은 문자 인증을 준비하고 있어요"라고만 나옵니다.
2. **연결 자격** — 전화 인증 + **다섯 가지 질문에 모두 답함**(이번 회차) + 필수 사진 3장 + 소개.
   - 2026-09-24 바꿈(대표 "그렇개 바꿔"). 예전 = 「맞아요」를 누른 말 5개. 「아니에요」로 버린 답은 세지 않고, 「처음부터 다시」 이전 답도 세지 않습니다.
   - 「맞아요」는 이제 자격이 아니라 **두 사람의 겹치는 말을 찾는 데만** 씁니다.
3. **후보 고르기** — 서버가 자격을 갖춘 사람 중 **같은 만남을 고른** 두 사람을 고릅니다. **맞다고 한 말이 겹치는 쌍이 먼저**, 겹친 말이 없는 쌍은 뒤에 「겹친 말 없음」으로 나옵니다(v1.2 — 예전엔 아예 안 나와서 아무도 「맞아요」를 안 누르면 후보가 0이었습니다). 차단한 사이·이미 결정한 쌍은 빠집니다.
4. **대표 승인** — 관리자 화면 `/doit/admin/mobile` → 왼쪽 메뉴 **「연결 승인」**. 「승인하고 첫 질문 보내기」 또는 「이 쌍은 넘기기」.
   - 승인 순간에 서버가 자격·목적·차단·겹침을 한 번 더 확인합니다.
   - 「겹친 말 없음」 쌍은 **「겹친 말 없이 승인」 → 「그래도 승인하고 첫 질문 보내기」** 두 번 눌러야 열립니다(취소 가능). 첫 질문은 고른 만남만 보고 만듭니다.
   - 승인하면 AI가 두 사람에게 **같은 첫 질문**을 만듭니다. 질문이 규칙(한 문장·45자 안팎·개인정보 묻지 않기·쓰지 않는 단어 없음·둘의 말을 그대로 옮기지 않기)에 걸리면 기본 질문 "처음 만난 사람에게 가장 먼저 들려주고 싶은 내 이야기는 뭐예요?"를 씁니다.
5. **첫 질문 동시 공개(blind-first)** — 연결 탭 맨 위 「내 연결」. 둘 다 답하기 전에는 상대 이름·사진·소개·답이 **서버에서 아예 내려오지 않습니다**.
   - **연결 동의(v1.2)**: 처음 답하기 전에 "두 사람이 모두 답하면 상대에게 내 닉네임·대표 사진·소개·고른 만남·이 질문에 쓴 답이 보여요 / 전화번호·이메일은 안 보여요 / 언제든 그만할 수 있어요"를 보여 주고 「확인했어요, 답할게요」를 눌러야 답 칸이 열립니다. 서버도 동의가 없으면 답을 저장하지 않습니다. 답하기 싫으면 그대로 두면 됩니다(아무것도 공개되지 않음).
   - **앱 홈 알림 카드(v1.2)**: 문자·푸시 알림이 없는 대신, 앱 홈을 열면 "새 연결에 첫 질문이 와 있어요 / 서로 열렸어요 / 상대가 이야기를 보냈어요" 카드가 먼저 보입니다. 누르면 내 연결로 갑니다. 이름·내용은 카드에 나오지 않습니다.
6. **이야기** — 둘 다 답하면 이름·대표 사진·소개·서로의 답이 열리고, 그 아래에서 글을 주고받습니다. 전화번호·이메일·링크·성적 표현은 보낼 수 없습니다.
7. **그만하기** — 「이 연결 그만하기」 → 「그만할게요」 또는 「차단하고 신고할게요」(신고는 기존 신고 목록 `user_reports` 에 들어감). 끝난 연결은 다시 이어지지 않습니다.

## 5. 남은 것·알고 있는 한계

- **알림 없음** — 연결이 생겨도 문자·푸시는 가지 않습니다. 대신 앱 홈을 열면 「내 차례」 카드가 먼저 보입니다(v1.2). 이야기는 30초마다 새로 불러오는 방식이라 실시간 채팅은 아닙니다.
- **겹치는 말** — v1.2 에서 풀었습니다: 겹친 말이 없어도 같은 만남이면 뒤쪽 후보로 나오고, 대표님이 한 번 더 확인하고 이을 수 있습니다.
- **약관(초안에 반영, v1.2)** — 이용약관 제7조·개인정보 처리방침 1·2·4·5항에 "연결되면 보이는 것·전화번호 수집·운영자 확인·문자 발송 업체"를 넣었습니다. 예전 문장 "사람 연결 기능은 준비 중이며 열리기 전에 동의를 받습니다"는 사실과 달라져서 뺐습니다. **문자 발송 업체 이름·나라는 제가 모르는 값이라 `[대표 확인]` 으로 남겼습니다.** 약관 판(v1.0)은 올리지 않았습니다 — 올리면 모든 회원에게 다시 동의를 받게 되므로 대표님 결정입니다. 문서 전체는 여전히 "검토 중인 초안" 표시가 붙어 있습니다.
- **사진 주소** — 상대 대표 사진은 10분짜리 서명 주소로만 나갑니다. 주소 안에 저장 폴더 이름(상대 계정 번호)이 들어갑니다. 비공개 저장소라 그 번호만으로는 아무것도 열 수 없습니다.
- **관리자 화면 기존 경고** — Supabase 보안 점검의 기존 경고(is_admin·key_spend 함수 공개 실행, 유출 비밀번호 차단 꺼짐)는 이번 작업과 무관하게 전부터 있던 것입니다. 새 표 3개는 "정책 0개" 안내만 뜨는데, 화면이 못 읽게 일부러 잠근 것입니다.
- 사용자가 자기 인증 상태나 역할을 직접 바꿀 수 있는지 의심했었는데, **확인해 보니 막혀 있습니다**(열 단위 권한에 없음 + 역할 잠금 장치).
