# PM 명세 — 매칭 5문항 대화 (대표 지시 2026-09-22 17:40 KST)

## 0. 대표가 말한 것 (원문 요지)
- "질문 다섯개면 상대방이 어떤 사람 원하는지 충분해"
- "처음에 설명을 해. 상대방 매칭을 위해서 물어보는 질문 다섯가지, AI가 데이터 수집 후 추천 상대 해준다고. 그대로 쓰지 말고 사용자가 이걸 해야 한다고 느끼게"
- "언제까지 내가 너랑 대화만 해야해?" / "질려서 못하겠다"
- "처음부터 다시 하기 버튼도 생성시켜서 사용자들이 처음부터 할 수도 있어"

## 1. 문제 정의 (측정된 사실)
- 대화에 **끝이 없었다.** 화면 바닥 문구가 그것을 명시하고 있었다: "대화의 길이는 정해져 있지 않아요. 내 속도로 이어가세요."
- 실기기 기록: 확인한 이해 **11개**를 쌓고도 대화가 계속됐다. 사용자는 언제 끝나는지 알 수 없었다.
- 진행 표시(n / 5)는 서버가 주제를 줄 때만 떠서, 대부분의 화면에서 **보이지 않았다.**
- 시작할 때 **왜 답해야 하는지 설명이 없었다.**

## 2. 구조 (확정)

### 화면 0 — 시작 안내 (첫 화면 위쪽)
- 제목: "다섯 가지만 물어볼게요."
- 동기: "이 다섯 가지 답이, **당신에게 누구를 소개할지 정하는 재료**예요."
- 다섯 칸 미리 보기: ① 어떤 만남을 원하는지 ② 어떤 사람에게 끌리는지 ③ 같이 뭘 하고 싶은지 ④ 상대가 알면 좋을 내 모습 ⑤ 어떻게 만나고 싶은지
- 약속: "짧게 한 줄이면 충분해요. 다 적으면 AI가 조건이 맞는 사람을 찾기 시작해요. **다섯 개를 넘겨서 묻지 않아요.**"
- 별도 클릭 없음 — 첫 질문과 같은 화면에 둔다(문턱을 늘리지 않는다).

### 화면 1~5 — 질문
- **맨 위에 진행 막대 + "n / 5"**. 항상 보인다. 화면에 한 곳만 둔다.
- 질문 45자 이내, 예시 괄호 없음, 무거운 추상 물음 금지(서버 v14).
- 확인 카드는 입력을 막지 않는다 — 「나중에 고를게요」로 넘어갈 수 있다.

### 화면 6 — 완료 (신규)
- "다섯 가지, 다 들었어요. 이제 상대를 찾을 차례예요."
- ✓ 다섯 가지 답을 모두 저장했어요.
- 다음에 일어나는 일 3줄: 사진 3장 + 소개 → 연결 자격 / 이름·사진은 서로의 첫 질문 뒤 공개 / 첫 100명 대표 승인
- 버튼: **사진과 소개 준비하기** · **연결 준비 상태 보기**
- **질문·입력창·진행 막대를 모두 닫는다.** 다음 질문을 서버에 요청하지 않는다.

### 언제든 — 처음부터 다시
- 바닥의 「처음부터 다시 시작하기」. 누르면 확인 한 번 받고 새 회차 시작.
- 지금까지 답은 지우지 않는다("이전 회차 이야기"로 남는다).

## 3. 끝나는 조건
`이번 회차에 남긴 답의 개수 >= 5` → 끝. 서버의 주제 판정과 무관하게 화면에서 확실히 끝낸다.
숫자 5는 `TOPICS.length`(매칭에 쓰는 칸 수)와 같은 값을 쓴다 — 두 곳이 어긋날 수 없다.

## 4. 바꾸지 않은 것
DB·RLS·마이그레이션 0건. 결제·가격 0건. 히어로·랜딩 0건. 4버튼(맞아요/조금 달라요/그게 아니에요/직접 설명할게요) 그대로. 확인한 이해 개수를 가짜로 올리지 않는다.

## 5. 검사 (가짜 AI 기준)
- 시작 안내에 다섯 칸과 이유가 있다 / 진행 표시가 한 곳뿐이다 / 다섯 개를 채우면 질문·입력창이 닫히고 완료 문구가 뜬다 / 끝난 뒤 다음 질문 요청 0건 — 네 가지를 검사로 고정했다.
