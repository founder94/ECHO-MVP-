## 2. 권장안(확정) 요약
- 첫 질문 하나만 고정: **"어떤 만남을 원하세요?"** — AI 대사 + 운영 DB 목적 타일 4개 + 한 줄 더 적기(선택).
- 서버가 **아직 안 나온 주제**(원하는 만남 → 끌리는 스타일 → 상대 성향 → 상대가 알아야 할 나 → 요즘 마음)를 방향으로만 주고, 질문 문장은 AI가 직전 원문·정정을 인용해 만든다. 순서 고정 아님, 이미 말한 주제는 건너뜀.
- 범위 이탈 = 받아 준 뒤 안 나온 주제로 복귀(고정 안내문 없음). 되묻기 = 앞 질문을 쉬운 말로. 저장 금지 입력(연락처·식별번호·링크·성적 표현) = 규칙으로 차단(유일한 고정 문구).
- 확인한 말 3개 이상 → 확인한 말로만 만든 소개 초안 → "이 초안 소개란에 넣기".
- 재방문 첫 줄 = 서버 질문(자동 요청). 실패하면 기존 버튼.
