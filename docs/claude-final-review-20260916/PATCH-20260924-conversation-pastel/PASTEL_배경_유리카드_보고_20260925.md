# ECHO 대화 화면 파스텔 배경 + 목적 카드 유리 보고 (2026-09-24 ~ 25)

## 근거 (대표 지시 순서)

1. 「CONVERSATION BACKGROUND ONLY · FINAL LOCK」
   - B구조 UI 전체 이식을 멈춘다.
   - 대화 화면 배경만 바꾼다.
2. 「배경색 이 색이야 그대로써」
   - 기준 색은 대표 첨부 캡처 = 옛 「오늘 내 마음의 날씨는 어때?」 화면이다.
3. 대표 선택 「D. 색 그대로 + 글자 남색」
   - 캡처 색을 그대로 쓰면 흰 글자가 읽히지 않는다. 그래서 대표가 D안을 골랐다.
4. 「CONVERSATION CARD TRANSPARENCY PATCH」
   - 목적 선택 카드 4개를 반투명 어두운 유리로 바꾼다.

운영 배포는 0건이다. DB·RLS·Migration·Auth·Secret·Model·Prompt·Agent Logic·Server·결제·가격·KEY·음악은 바꾸지 않았다.

- **범위 밖 변경을 되돌렸다.**
  - 앞선 지시(B-style 이식)로 만들던 변경이 커밋 전 작업 폴더에 있었다.
    - Pretendard 글꼴, 흰 버튼, 입력창, 진행 표시, 질문 등장 움직임

  - 되돌린 뒤 작업 폴더를 저장소 원본과 글자 단위로 대조해 **같음**을 확인했다. Agent v1.1 코드는 그대로다.
  - 음악 작업은 지우지 않고 작업 공간에 따로 보관했다(이 커밋에 없음).
- **측정 도구 실수 2건. 모두 다시 쟀다.**
  - ① 설명 글자를 숨기는 규칙이 새 색 규칙보다 약해서 글자가 남았다. 그래서 대비가 1로 잘못 나왔다.
  - ② 한 줄에 넣은 `//` 주석이 같은 줄의 "어두운 바탕 위 글자는 뺀다" 조건까지 꺼 버렸다.
  - 아래 숫자는 모두 고친 도구로 다시 잰 값이다.
- **새 검사도 처음에 한 번 틀렸다.**
  - CSS 설명 주석의 "Readdy" 낱말까지 세어 실패로 나왔다.
  - 실제 규칙만 보도록 고쳤다.

### ① 배경 (파스텔)

- 바탕 그라데이션과 가장자리 빛은 **대표 첨부 캡처에서 잰 색**이다.
  - 그 화면의 파스텔은 CSS 값이 아니다. 바깥 서버(Readdy)의 **배경 사진** 색이다.
  - 코드에서 찾은 파스텔 값은 `PastelBlobs.tsx` 의 빛 번짐 6개(투명도 .08~.15)뿐이다.
  - 그 값만으로는 캡처 색이 나오지 않는다(검은 바탕에 옅은 번짐 정도).
  - 그래서 사진은 쓰지 않고 색만 옮겼다. 바깥 주소는 0개다.
- 잰 색은 아래와 같다(캡처의 화면 영역, 격자 위치마다 31×31 평균).
  - 가운데 세로 줄: `#6cdfbc`(맨 위) → `#80ebac`(20%) → `#88dfaa`(35%) → `#cae2b3`(50%) → `#e7eaa5`(62%) → `#f2eeb6`(72%) → `#e4da8f`(82%) → `#c4a96c`(맨 아래)
  - 가장자리 빛:
    - 왼쪽 위 초록 `#79ee9c`
    - 오른쪽 청록 `#60cfd0`
    - 왼쪽 아래 코랄 `#d88a7b`
    - 오른쪽 아래 갈색 `#96774c`
- Glow(빛 번짐)는 옛 코드 `PastelBlobs.tsx` 의 6개를 **색·크기·위치 그대로** 썼다.
  - `rgba(160,255,200,.15)` 28rem · `rgba(160,220,255,.12)` 24rem · `rgba(255,235,160,.10)` 30rem
  - `rgba(255,180,180,.12)` 20rem · `rgba(160,255,220,.10)` 26rem · `rgba(200,230,255,.08)` 32rem
- 움직임은 옛 코드 `float-bg`(20초 주기, 1% 이동) 하나뿐이다.
  - 「움직임 줄이기」 설정이면 멈춘다.
  - 날씨 입자, 마우스 추적, 날씨 기능은 0이다.
- 덮개(`--echo-pastel-veil`)는 **0**이다. 대표 「그대로 써」에 따른 값이다.
  - 참고로, 흰 글자를 그대로 두고 기준 대비를 맞추려면 .86이 필요했다(실측).
  - 그러면 색이 어두운 올리브로 바뀐다.

### ② 배경 위 글자 = 남색 (대표 선택 D)

- 캡처 색 그대로면 흰 질문 글자의 대비가 **1.1~1.4:1** 이다(기준 4.5:1). 거의 읽히지 않는다.
  - 비교 그림은 `배경_4가지_비교_390.png` 이다.
- 대표 선택에 따라 **배경 위에 바로 놓인 글자만** `#0c1526`(옛 B 화면 주요 버튼의 글자색)으로 바꿨다.
- 어두운 카드·버튼·입력창 안의 글자는 그대로다.
- 글꼴·크기·굵기·문구·배치는 0건 변경이다.

- 설명 글자는 원래 색으로는 .8 에서도 미달했다(3.54). 그래서 밝기만 올렸다.

  - 파스텔이 카드 뒤에서 보인다는 뜻이다.
- 크기·자리·글꼴·문구는 0건 변경이다. 다른 화면의 카드는 그대로다(검사로 막음).
