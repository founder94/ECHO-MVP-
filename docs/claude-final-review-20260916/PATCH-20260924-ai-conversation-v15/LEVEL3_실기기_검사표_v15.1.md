# LEVEL 3 실기기 검사표 — v15.1 (대표님이 실제 사용자처럼 하는 검사)

- 전제: **서버 v15.1 운영 배포 + 42차 앱 업로드가 둘 다 끝난 뒤**에만 할 수 있다. 둘 다 아직 안 했다(대표 승인 필요).
- 계정: 검사 계정 0423doit@gmail.com 하나만. 비밀번호는 채팅에 적지 않는다.
- 결과는 칸마다 **통과 / 실패 / 모르겠음** 중 하나와 화면 캡처 1장. 캡처에 전화번호·이메일이 보이면 가려서 보낸다.
- 이 검사 전에는 "AI 최종 PASS·최종 완료·비공개 베타 가능"이라고 쓰지 않는다.

## 시작
1. 휴대폰에서 app.do-it.company 를 연다.
2. 로그인한다.
3. 아래 탭 「홈」 → 「처음부터 다시 시작하기」 → 확인 창에서 「처음부터 다시」를 누른다(지난 답은 지워지지 않는다).

## 5턴 대화 (그대로 따라 친다)

| 순서 | 내가 칠 말 | 확인할 것 | 결과 |
|---|---|---|---|
| 1 | 첫 질문에 `진지하게 알아가고싶어` | 다음 질문이 이 말에서 이어지는가(엉뚱한 주제 아님) | |
| 2 | 다음 질문에 `잘 웃는 사람` | 같은 말을 되묻지 않는가("진지하게 알아가고 싶어요?" 류 없음) | |
| 3 | AI 첫 줄(받아 주는 말)이 내 뜻과 다르면 `그게 아니에요` (같으면 이 칸은 건너뜀) | "어떤 뜻이었는지 한 줄로" 안내가 **한 번만** 나오는가 | |
| 3-1 | 이어서 `아니야` | 같은 안내가 또 나오지 않고 다른 질문으로 넘어가는가 | |
| 4 | 다음 질문에 `왜 이런 걸 물어봐?` | 답으로 세지 않고(위 n / 5 그대로) 먼저 대답한 뒤 같은 질문을 다시 보이는가 | |
| 5 | 다음 질문에 `할말이없다 휴` | 답으로 세지 않고 「다른 질문 받기 / 계속 답할게요 / 오늘은 여기까지」가 나오는가 | |
| 6 | 「다른 질문 받기」 → 새 질문에 `모르겠어요` | n / 5 가 하나 오르는가(진행은 셈) | |
| 7 | 여기서 **앱을 완전히 닫았다가 다시 열고** 대화로 돌아간다 | 방금 질문이 그대로 있는가 · 3번에서 아니라고 한 말이 다시 나오지 않는가 | |
| 8 | 남은 칸을 `천천히 알아가고 싶어요`, `주말에 산책하면서 이야기하는 거요` 로 채운다 | 매 질문이 앞 답과 이어지는가 · 답마다 네 버튼 카드가 **안** 뜨는가 | |

## 다섯 번째 답 뒤

| 확인할 것 | 결과 |
|---|---|
| 「내가 이렇게 이해했어요」 카드가 **한 번** 나오고 네 버튼(맞아요/조금 달라요/그게 아니에요/직접 설명할게요)이 거기에만 있는가 | |
| 카드 항목에 3번에서 아니라고 한 말, 「할 말이 없다」, 「모르겠다」가 **없는가** | |
| 「맞아요」를 누른 뒤 「내 이해」 화면에 맞다고 한 항목만 보이는가 | |
| 끝 화면에 "「모르겠어요」처럼 넘긴 답 1개는 연결 자격에 세지 않아요"가 보이는가 | |
| 아래 탭 「연결」 → 「다섯 가지 질문」 줄이 **4 / 5** 이고, 넘긴 답 안내 + 큰 버튼 「처음부터 다시 답하기」가 보이는가 | |
| 새로고침(화면을 아래로 당기기)해도 카드·끝 화면이 그대로인가 | |
