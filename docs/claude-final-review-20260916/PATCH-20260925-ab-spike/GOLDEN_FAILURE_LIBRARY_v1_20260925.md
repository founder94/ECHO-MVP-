## GF-01 같은 뜻 질문 반복
- **실제 사용자 상황** [운영 실측]
  - 대표 Galaxy, 2026-09-25 04:20~04:26 KST.
  - 목적은 「아직 정하지 않았어요」.
  - 사용자는 「나 진심이라고 적은거 같은데」, 「적었자네」, 「몇번째 같은말이야!!」라고 말했다.
- **실패 유형**: 표현만 바꾼 같은 뜻 질문이 연달아 나갔다.
  - 「사람을 알아가는 데 어떤 점이 가장 중요하다고 생각해요?」
  - 「사람을 알아가면서 어떤 점이 가장 즐거운 것 같아요?」
  - 「진심으로 사람을 알아가는 데 어떤 점이 특별하다고 느끼나요?」
  - 「사람을 진심으로 알아가는 과정에서 어떤 점이 가장 마음에 드나요?」
- **원인 Layer**
  - Orchestration: 반복 검사가 글자쌍 비교다(sim > 0.6 또는 overlap > 0.7).
    - 위 4문장 10쌍은 모두 통과했다(최대 0.39 / 0.59).
    - A 에는 질문의 "뜻"을 적는 칸이 없다.
  - Context: GF-04 가 겹친다.
  - 모델 탓인지는 분리되지 않았다.
- **A 결과**: 운영에서 4번 나갔다. 검사는 하나도 막지 못했다.
- **B 결과**: 실제 AI 로는 확인 불가.
  - 구조상 LLM 이 적은 `question_intent` 를 서버가 정규화해 비교하고, 답한 의도·거절한 의도를 막는다. 이것은 [MOCK] 검사만 통과했다.
  - **[HEURISTIC / EXPERIMENT ONLY]** 의도 비교는 "정규화 뒤 글자가 같은가"만 본다.
    - LLM 이 같은 뜻에 다른 이름을 붙이면 놓친다(미탐).
    - 오탐·미탐 비율은 실제 AI 없이는 측정할 수 없다.
- **재현 여부**: 운영에서 1회 관측됐다. 실제 AI 로 다시 돌린 적은 0회다.
- **해결 후보**
  - 질문마다 의도를 남기고, 같은 의도를 서버가 막는다(B 구조).
  - 문제제기가 오면 직전 의도를 거절 목록에 넣는다.
- **검증 상태**: 미검증.
