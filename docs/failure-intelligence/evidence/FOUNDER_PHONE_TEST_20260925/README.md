## 코드에서 확인한 원인(core-0.1 · `product/spike/core-20260925/core.mjs`)
1. **끝나지 않음**: `finish = out.kind === 'stop' || enough(st)`, `enough` = 네 영역(intent·person·values·pace) 모두 들음.
   - AI 가 기억을 intent·person 에만 넣어, pace 가 끝까지 비었다.
   - 질문 수 상한이 없었다(당시 계약 A-19 「질문 수 강제 금지」를 그대로 따름). → 13턴.
2. **한 주제 파고들기**: TURN_PROMPT 가 「출발점은 방금 한 말 · 한 단계만 더」를 가장 강하게 지시했다.
   - 영역은 「자연스러울 때만」 방향으로 줬다.
   - 그래서 방금 말(편함)에 계속 붙어 파고들었다. 넘기기·피로를 종류로 따로 두지 않아(repair/stop 만) 「다음 질문」이 반영되지 않았다.
3. **반말**
   - 말투를 사용자가 고르게 하지 않았다.
   - 프롬프트는 「해요체」 한 줄뿐이고, 사용자 말투를 따라가지 말라는 지시가 없었다.
   - 첫 질문은 대표가 말하기 전에 이미 반말이었다 → 모델(Claude 빠른 등급)이 지시를 어긴 것 + 약한 지시.
4. **「RELATIONSHIP_INTENT」 노출(내 실수)**
   - OPENING_PROMPT 에 「(RELATIONSHIP_INTENT)」라는 내부 이름을 괄호로 넣었다.
   - 모델이 그 이름을 질문 칸에 그대로 썼다.
   - 서버는 빈 질문·금지어만 봐서 막지 못했다.
