# Failed Solutions Archive (v1 · 2026-09-25)

시도했지만 새 실패를 낳았거나 효과가 없었던 해결책이다. **지우지 않는다.** 같은 방법을 다시 쓰기 전에 여기부터 본다.
공통 교훈: 실패 하나를 막으려고 문자열 규칙·글자 검사를 더하면, 정상 답이나 정상 질문을 죽이는 새 실패가 생겼다(과잉 Guard).
